# 掼蛋

四人分组的网页掼蛋。你坐南家，对家是队友，上家和下家由电脑打。纯静态页面，用手机或电脑打开就能玩。

在线地址：<https://dannywang0822.github.io/guan-dan/?v=4>

## 怎么玩

1. 打开页面，选电脑难度（轻松、均衡、精算，三家同一档），点「开始对局」。第一局打 2，由你先出。
2. 点下手牌选出要出的牌，再点「出牌」。压牌可以出更大的同型牌，也可以出炸弹；不想出就点「不出」。
3. 打完一局看名次和升级。进贡、还贡之后进入下一局，直到有一队在 A 上打出头游且队友不是末游，即过 A 获胜。点「再来一局」重新从 2 开始。

「提示」会给一个合法出法。「理牌」在点数、花色、牌型之间切换，规则条留在牌桌上；选中牌时写出这种牌型怎么比。自己的手牌分成两排完整摆开，不重叠。任一家手牌少于 10 张时，记牌器自动打开，只显示各家张数和未出牌的花色、点数。规则全文在游戏里的「规则」里。

## 规则摘要

- 两副牌共 108 张，四人各 27 张。你和对家一队。
- 从 2 打到 A。本局级数是上一局赢家升级之后的级数，第一局打 2。红桃级牌是逢人配。
- 牌型：单张、对子、三张、三带二、五张顺子、木板（三连对）、钢板（两连三张）、炸弹、同花顺、天王炸。
- 单张、对子、三张、三带二、炸弹：大王 > 小王 > 级牌 > A > K > … > 2（级牌从原位抽出）。
- 顺子、木板、钢板按自然点数衔接，级牌回到原位，不另算。A2345 最小，10JQKA 最大。木板允许 A23，钢板允许 A2。
- 炸弹张数多为大；同张数比点数。同花顺大于四炸、五炸，小于六张及以上的炸弹。四王最大。
- 头游 + 二游升 3 级，头游 + 三游升 2 级，头游 + 末游升 1 级。
- 发下一局后进贡：末游交最大非逢人配给头游；双下时三游、末游都交，大的给头游。对方还一张牌面 ≤10 的牌。进贡方有两张大王则抗贡。
- 打到 A 时，必须头游且队友不是末游才算过 A。

电脑三档：轻松合法跟牌、偏出小牌；均衡尽量出小牌型、留炸弹，队友领出的大牌一般不压；精算记公开牌，配合让牌与拦截，炸弹时机更稳，残局按手数取舍。

## 本地打开

不需要构建。在仓库根目录起一个静态服务后打开 `index.html`：

```bash
python3 -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/?v=4>。直接用浏览器打开本地文件也可以，但模块脚本在部分浏览器里会被拦住，建议用上面的方式。

规则测试：

```bash
node --experimental-loader ./tests/loader.mjs tests/rules.mjs
```

## GitHub Pages

页面从 `main` 分支的根目录发布（`index.html` 在仓库根目录）。仓库里放了 `.nojekyll`，避免 Jekyll 丢掉文件。

样式、脚本和牌面的地址都带 `?v=4`，更新后改这个版本号即可避开旧缓存。

牌面是宣纸底上的朱砂与松烟墨，红黑分开，方便缩小后认牌。
