# 掼蛋

四人分组的网页掼蛋。你坐在下方，对家是队友，上家和下家由电脑打。纯静态页面，用手机或电脑打开就能玩。

在线地址：<https://dannywang0822.github.io/guan-dan/?v=2>

## 怎么玩

1. 打开页面，点「开始游戏」。第一局打 2，由你先出。
2. 点下手牌选出要出的牌，再点「出牌」。压牌可以出更大的同型牌，也可以出炸弹；不想出就点「不出」。
3. 打完一局看名次和升级。进贡、还贡之后进入下一局，直到有一队在 A 上打出头游且队友不是末游，即过 A 获胜。点「再来一局」重新从 2 开始。

「提示」会给一个合法出法，「理牌」在点数、花色、分组之间切换。规则全文在游戏里的「规则」里。

## 规则摘要

- 两副牌共 108 张，四人各 27 张。你和对家一队。
- 从 2 打到 A。本局级数是上一局赢家升级之后的级数，第一局打 2。红桃级牌是逢人配。
- 牌型：单张、对子、三张、三带二、五张顺子、木板（三连对）、钢板（两连三张）、炸弹、同花顺、天王炸。
- 单张、对子、三张、三带二、炸弹：大王 > 小王 > 级牌 > A > K > … > 2（级牌从原位抽出）。
- 顺子、木板、钢板按自然点数衔接，级牌回到原位。A2345 最小，10JQKA 最大。木板允许 A23，钢板允许 A2。
- 炸弹张数多为大；同张数比点数。同花顺大于四炸、五炸，小于六张及以上的炸弹。四王最大。
- 头游 + 二游升 3 级，头游 + 三游升 2 级，头游 + 末游升 1 级。
- 发下一局后进贡：末游交最大非逢人配给头游；双下时三游、末游都交，大的给头游。对方还一张牌面 ≤10 的牌。进贡方有两张大王则抗贡。
- 打到 A 时，必须头游且队友不是末游才算过 A。

电脑会出合法牌：优先小的同型牌，尽量留炸弹，队友领出的大牌一般不压。

## 本地打开

不需要构建。在仓库根目录起一个静态服务后打开 `index.html`：

```bash
python3 -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/?v=2>。直接用浏览器打开本地文件也可以，但模块脚本在部分浏览器里会被拦住，建议用上面的方式。

规则测试：

```bash
node --experimental-loader ./tests/loader.mjs tests/rules.mjs
```
